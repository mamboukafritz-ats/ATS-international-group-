# ATS International Group — Corporate Website

Site corporate responsive en français / anglais, sans dépendance externe.

## Contenu
- Hero corporate ATS International Group
- Présentation du groupe
- Maisons / activités : Maisons Fritz, CongoToit, NexAfrica Partners, Benazo Production
- Présidence : Fritz Mambouka
- Vision du groupe
- Section contact prête à recevoir les coordonnées officielles
- Version mobile et desktop
- Bascule FR / EN
- Logo ATS fourni intégré

## Lancer localement
```bash
npm start
```
Puis ouvrir `http://localhost:3000`.

## Railway
Ce projet peut être déployé tel quel sur Railway. Railway détecte `package.json` et lance `npm start`. Le serveur utilise automatiquement la variable `PORT` fournie par Railway.

## Note éditoriale
Les informations de structure et de gouvernance utilisées dans cette maquette proviennent du brief fourni par le propriétaire du projet. Une vérification web a aussi permis de confirmer l'existence historique d'un Jean-Daniel Mambouka dans la diplomatie gabonaise, notamment comme ambassadeur du Gabon aux États-Unis à la fin des années 1970. La relation familiale exacte n'a pas été utilisée comme donnée sourcée indépendante : elle reste une information fournie par le brief.
